# Firebase Studio

This is a NextJS starter in Firebase Studio.

To get started, take a look at src/app/page.tsx.

## TestSprite

This repo is wired for project-level TestSprite MCP usage.

1. Copy `.env.testsprite.example` to `.env.testsprite.local`
2. Set `TESTSPRITE_API_KEY`
3. Run `npm run testsprite:doctor`
4. Start the app with `npm run dev`
5. Open the repo in a supported MCP client and ask: `Help me test this project with TestSprite.`

More detail: [docs/testsprite.md](/Users/khetsophonchapha/Documents/App/drive%20onboard/docs/testsprite.md)
